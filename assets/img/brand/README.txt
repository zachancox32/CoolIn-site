COOLIN — brand assets (lockup 16B · icon 14A)
=============================================

Wordmark   Archivo ExtraBold (800). Free from Google Fonts:
           https://fonts.google.com/specimen/Archivo
           The SVGs reference Archivo by name — install the font, or ask me for
           a version with the letters converted to outlines for print suppliers.
Strapline  Archivo Bold (700), uppercase, 12% letter-spacing.

  Ice           #5EC3E0   crystal and wave on dark grounds
  Terracotta    #E2673B   lower wave (heating)
  Warm light    #F0845A   lower wave on dark grounds
  Strapline     #3D5D6E   on light   /  #9EBDCA on dark

Rules
  Clear space   one crystal width on every side.
  Minimum size  wordmark 26mm / 100px wide in print and on screen.
                Below that use the crystal mark on its own.
  Do not        stretch, add shadows or gradients, recolour the waves
                individually, or set the strapline in another typeface.

Email signatures (two versions — pick one)
  coolin-email-signature.html       compact: hex icon + wordmark on one line.
  coolin-email-signature-logo.html  name and title, then the full 16B lockup
                                    beneath. Use this when you want the logo
                                    to reproduce exactly.

  Both open straight from this folder with the images working. To use:
    1. Open the file in a browser.
    2. Select everything inside the white box and copy.
    3. Paste into Gmail (Settings > General > Signature) or
       Outlook (File > Options > Mail > Signatures).
    4. Upload the PNG from png/ to your website and change the image src to
       that URL, so the logo loads for every recipient rather than only you.
    5. Replace the placeholder name, title, phone, email, domain, town and
       company number with your own.
